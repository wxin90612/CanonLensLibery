# 镜头速查 - Canon EF/RF + Tamron + Sigma 镜头速查工具

## 1. 产品概述

一款专业的单反/无反镜头速查工具，涵盖佳能EF卡口、佳能RF卡口、腾龙、适马镜头库。用户可快速查询镜头年份、型号、民间绰号、保有量、二手价格、常见问题、优缺点及产品图片。

**目标用户**：摄影爱好者、二手镜头交易者、摄影器材测评人员

**核心价值**：帮助用户在购买二手镜头时快速了解镜头背景信息和市场行情

---

## 2. 核心功能

### 2.1 功能模块

1. **首页/搜索页**
   - 品牌筛选（佳能、腾龙、适马）
   - 卡口筛选（EF卡口、RF卡口）
   - 类型筛选（定焦、变焦）
   - 焦段筛选（超广角、广角、标准、中焦、长焦、超长焦）
   - 光圈筛选
   - 关键词搜索

2. **镜头详情页**
   - 基础信息卡片
   - 产品图片展示
   - 价格走势参考
   - 优缺点分析
   - 常见问题FAQ
   - 用户评价摘要

3. **收藏对比功能**
   - 添加到收藏夹
   - 镜头参数对比

4. **价格参考**
   - 新品价格
   - 二手价格区间（闲鱼/转转参考）
   - 保值率指标

## 3. 数据结构

| 字段名 | 说明 | 示例 |

## 4. 用户界面设计

### 4.1 设计风格

**概念方向**：复古胶片相机美学 + 现代卡片式布局

**设计语言**：
- 主题色：深灰炭黑 + 暖橙琥珀色点缀
- 背景：深色主题，减少眼睛疲劳
- 卡片：磨砂玻璃质感
- 字体：几何无衬线 + 中文衬线
- 交互：流畅滑动、弹性动画

**色彩方案**：
```
--bg-primary: #0d0d0d
--bg-secondary: #1a1a1a
--bg-card: rgba(255, 255, 255, 0.05)
--accent-primary: #ff8c42 (琥珀橙)
--accent-secondary: #ffd700 (金色)
--text-primary: #ffffff
--text-secondary: #999999
--border: rgba(255, 255, 255, 0.1)
```

### 4.2 页面结构

1. **顶部导航栏**
   - Logo + 标题
   - 筛选按钮入口

2. **筛选区域**
   - 标签式筛选（品牌/卡口/类型）
   - 下拉筛选（焦段/光圈）

3. **镜头卡片网格**
   - 2列布局（移动端）/ 3-4列（桌面端）
   - 卡片包含：图片、型号、绰号、价格区间

4. **详情弹窗/页面**
   - 全屏详情展示
   - 参数表格
   - 优缺点标签
   - FAQ折叠面板

---

## 5. 技术实现

### 5.1 技术栈

- **前端**：React 18 + Vite
- **样式**：CSS Modules / TailwindCSS
- **图标**：Lucide React
- **动画**：Framer Motion (可选)

### 5.2 数据管理

- 使用本地JSON数据文件
- 支持筛选、搜索、排序
- LocalStorage 存储用户收藏

## 7. 响应式设计

- **桌面端（>1024px）**：3-4列卡片，侧边筛选栏
- **平板端（768-1024px）**：2-3列卡片，顶部筛选
- **移动端（<768px）**：单列卡片，底部筛选抽屉
